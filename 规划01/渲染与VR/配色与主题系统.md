# 配色与主题系统（权威）

## 范围

本页定义“主题/配色”的单一权威：**token（语义色名）集合、各主题的调色板（token→颜色值）、跨层映射规则与验收标准**。实现时 UI（DOM/CSS）与游戏画面（p5/Pixi/Three）必须消费同一套 token，而不是各自硬编码颜色。

来源（libgdx 版权威参考）：

```
temp/duel-libgdx/game0003/assets/theme/darkTheme.yaml
temp/duel-libgdx/game0003/game0003-core/src/main/java/pama1234/gdx/game/duel/util/theme/ThemeData.java
```

## 核心约束

- token 名必须稳定、跨渲染后端一致；不得出现“同语义色在不同 renderer 各自起名/各自取值”的分裂。
- 调色板的权威值只保留在本页；其他文档只引用，不重复拷贝表格。
- 主题切换必须同时影响：UI（CSS variables）+ 游戏画面（清屏/线条/文本/特效）+（未来）three.js 场景材质与 Troika Text。

## 颜色格式规范

本页所有颜色值使用 **RGBA8888** 的 32bit 十六进制字符串：

- 规范格式：`0xRRGGBBAA`
- 例：`0x1e1e1eff` 表示 R=0x1e, G=0x1e, B=0x1e, A=0xff

实现侧常用转换规则：

- CSS：`0xRRGGBBAA` → `#RRGGBBAA`
- Canvas/Pixi 常量：`0xRRGGBBAA` → `0xRRGGBB` + 单独 alpha（或拆成 rgba）
- Three：拆为 0..1 的 `r,g,b,a`（注意 alpha 是否参与混合、是否预乘）

## Token（语义色）清单

token 名必须与 libgdx `ThemeData` 字段一致（共 18 个）：

| token | 语义 | 约束/备注 |
|------|------|----------|
| background | 对局画布背景底色 | UI 的 `--bg` 应与其保持一致 |
| backgroundLine | 场地/辅助线颜色 | 不用于 UI 边框（UI 有自己的 panel 体系） |
| text | 文本颜色 | UI 的 `--fg` 应与其保持一致 |
| stroke | 通用描边色 | 对局渲染的“默认线条”走它 |
| player_a | 玩家 A 语义色 | 与“P1/P2 控制权”解耦；只表示阵营/角色 A |
| player_b | 玩家 B 语义色 | 同上 |
| playerDamaged | 受伤/危险提示色 | 不等同于 accent |
| ring | 环/圈指示色 | |
| particleDefault | 默认粒子色 | |

## 与设置系统的关系

- `themeMode` 仅决定选择哪个调色板（light/dark，或跟随系统）。
- `accentColor` 是 UI 强调色（可用于按钮高亮、滑条、focus ring 等），默认不参与对局语义色 token；如需影响对局视觉，必须先在本页新增明确的 token 扩展并给出规则。

## 跨层映射规则（UI 与游戏画面）

### UI（DOM/CSS）

UI 的最低要求是把全局背景/前景与 token 对齐：

- `--bg` ← `background`
- `--fg` ← `text`
- `--accent` ← `accentColor`

面板/输入框等半透明 surface（例如 `--panel-bg`/`--overlay-bg`/`--input-bg`）允许作为 UI 专用派生色，但其派生必须只依赖 `background/text` 与固定 alpha，不得引入额外“第三套”手写基色。

### 游戏画面（p5/Pixi/Three）

- 画布清屏色必须来自 `background`。
- 对局默认线条/描边必须来自 `stroke`。
- 场地辅助线来自 `backgroundLine`。
- 玩家填充色来自 `player_a/player_b`（与 P1/P2 映射在实现层定义，但必须稳定且文档化）。
- 传送/长弓/受伤等特效色分别来自对应 token（`teleport* / longbow* / playerDamaged`）。

#### 实现约定（duel-app 落地）

- P1 使用 `player_a`，P2 使用 `player_b`。
- 粒子（按几何语义映射到 token）：
  - type=0（点粒子）→ `particleDefault`（alpha 随寿命衰减）
  - type=1（方块粒子）→ `squareParticles`（alpha 随寿命衰减）
  - type=2（长线/光束）→ `longbowLine`（alpha 随寿命衰减）
  - type=3（圆环）→ 默认 `ring`；若属于长弓特效环则使用 `longbowEffect`（实现侧根据粒子颜色特征做稳定判别，避免引入新字段）

#### 代码入口（便于定位）

- token 与 light/dark 调色板：`duel-app/src/theme/gameTheme.ts`
- themeMode/system 解析并下发渲染器：`duel-app/src/duel.ts`（`setSettings()`）
- 渲染器后端接口：`duel-app/src/frontend/renderBackend.ts`（`setGameTheme()`）

## 验收标准（最小闭环）

- 切换 `themeMode` 后，UI（背景/文字/面板）与对局画布（清屏/线条/特效）同时变化，且 token 语义保持不变。
- 同一主题下，p5/Pixi/Three 三个渲染后端的关键颜色一致（允许抗锯齿差异，不允许色相/明度漂移）。
- 不允许在 renderer 内新增语义色硬编码（除非是临时调试可视化，且不进入 release 路径）。
