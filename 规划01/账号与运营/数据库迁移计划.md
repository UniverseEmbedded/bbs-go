# 数据库迁移计划

本文档定义从文件存储（JSON）到 SQLite 数据库的迁移方案。

---

## 背景

现有 Go 服务端使用文件存储（JSON）保存数据。为支持更复杂的查询、事务和并发访问，需要迁移到 SQLite。

---

## 迁移目标

| 目标 | 说明 |
|------|------|
| 数据安全 | 迁移过程不丢失数据 |
| 可回滚 | 迁移失败可回退到文件存储 |
| 最小停机 | 尽量减少服务中断时间 |
| 验证完整 | 迁移后数据完整性可验证 |

---

## 迁移步骤

### 阶段 1：准备

1. **备份现有数据**
   - 复制所有 JSON 文件到备份目录
   - 记录文件修改时间

2. **创建 SQLite 表结构**
   - 按 [账号系统设计.md](./账号系统设计.md) 中的表结构创建
   - 使用迁移脚本初始化

3. **编写迁移脚本**
   - 读取 JSON 文件
   - 转换为数据库记录
   - 写入 SQLite

### 阶段 2：迁移执行

1. **停服公告**
   - 提前通知用户
   - 预计停机时间

2. **停止服务**
   - 停止 Go 服务端
   - 确保无写入操作

3. **执行迁移**
   ```bash
   # 迁移脚本示例
   go run scripts/migrate-to-sqlite.go \
     --data-dir ./data \
     --db-file ./duel.db \
     --backup-dir ./backup
   ```

4. **验证数据**
   - 对比 JSON 记录数与数据库记录数
   - 抽样检查关键字段
   - 运行完整性检查脚本

5. **切换配置**
   - 修改配置文件指向 SQLite
   - 重启服务

### 阶段 3：验证与清理

1. **功能验证**
   - 登录测试
   - 用户数据查询
   - 门禁检查

2. **性能验证**
   - 响应时间对比
   - 并发测试

3. **清理备份**
   - 确认迁移成功后删除旧 JSON 文件
   - 保留备份一段时间

## 迁移脚本示例

```go
package main

import (
    "encoding/json"
    "fmt"
    "os"
    "path/filepath"
    
    _ "github.com/mattn/go-sqlite3"
)

type LegacyUser struct {
    ID          string `json:"id"`
    Email       string `json:"email"`
    DisplayName string `json:"display_name"`
    Status      string `json:"status"`
    CreatedAt   int64  `json:"created_at"`
}

func migrateUsers(dataDir string, db *sql.DB) error {
    data, err := os.ReadFile(filepath.Join(dataDir, "users.json"))
    if err != nil {
        return err
    }
    
    var users []LegacyUser
    if err := json.Unmarshal(data, &users); err != nil {
        return err
    }
    
    for _, u := range users {
        _, err := db.Exec(`
            INSERT INTO users (id, display_name, status, created_at, updated_at)
            VALUES (?, ?, ?, ?, ?)
        `, u.ID, u.DisplayName, u.Status, u.CreatedAt, u.CreatedAt)
        if err != nil {
            return fmt.Errorf("insert user %s: %w", u.ID, err)
        }
    }
    
    return nil
}

func main() {
    // 初始化数据库连接
    // 执行迁移
    // 验证结果
}
```

## 回滚方案

如果迁移失败：

1. **停止服务**
2. **恢复配置**
   - 修改配置指向文件存储
3. **恢复数据**
   - 从备份目录复制 JSON 文件
4. **重启服务**
5. **调查失败原因**
