# 本地双人设计

本文档定义本地双人模式的核心设计，目标是：**不影响单人模式、极简可用、新玩家能理解**。

---

## 模式定义

引入运行模式：

```
controlMode = "single" | "local_dual"
```

- `single`：单人模式，P1 vs AI
- `local_dual`：本地双人模式，P1 vs P2

---

## 核心原则

1. **双人模式不能影响单人模式**：单人模式下键盘映射、UI布局、游戏逻辑完全不变
2. **极简设计**：不做蓄力UI、命中提示、状态卡片等额外HUD
3. **标签仅准备阶段显示**：3秒倒计时显示P1/P2标签，开战后隐藏

---

## 桌面端设计

### 布局

- 玩家分坐左右两侧
- P1坐左侧，P2坐右侧
- 游戏画面居中，双方共享同一视角

### 键盘映射

#### 单人模式（保持现状）

- 移动：WASD 和 方向键 都算到 P1
- 攻击：沿用现有按键（Z/X 或其他）

#### 双人模式（拆分）

| 玩家 | 移动 | 普攻 | 大招 |
|------|------|------|------|
| P1 | TFGH（当前实现） | Z | X |
| P2 | 方向键 | , | . |

全局键（不属于任何玩家）：
- R：重开
- P：帮助

### Ready流程

1. 进入双人模式后，显示双方键位提示卡片
2. P1显示："按【普攻】确认准备"
3. P2显示："按【普攻】确认准备"
4. 双方都ready后，开始3秒倒计时
5. 倒计时期间显示P1/P2标签
6. "Go"后标签隐藏，对战开始

---

## 手机端设计

### 布局

采用上下对坐布局：
- P1坐底部，控件在下半屏（正常显示）
- P2坐顶部，控件在上半屏（整体倒置180°）

### P2 UI倒置实现

P2的整个UI容器（HUD + 控件）包在一个div里，使用CSS：

```css
#p2-layer {
  transform: rotate(180deg);
  transform-origin: center;
}
```

注意事项：
- 游戏画面canvas不倒置
- 触控按钮用DOM实现（浏览器会自动处理变换后的命中测试）
- 摇杆允许区域按"各自半屏"判断

### 控件布局

每个玩家一套控件：
- 左侧：移动摇杆（半透明圆盘）
- 右侧：两个按钮（普攻、大招）

### 安全区处理

使用`env(safe-area-inset-*)`给上下留边。P2倒置后，上下边距视觉互换，需要分别设置。

## 输入层设计

### 双通道输入

新增`DualInputSnapshot`：

```ts
type DualInputSnapshot = {
  p1: PlayerInputLike;
  p2: PlayerInputLike;
};
```

### 输入策略分发

```ts
function getInput(mode: 'single' | 'local_dual'): DualInputSnapshot {
  if (mode === 'single') {
    return {
      p1: mergedKeyboardOrTouch(),  // 单人：合并WASD+方向键
      p2: ZERO_INPUT
    };
  } else {
    return {
      p1: p1KeyboardOrTouch(),      // 双人：P1专用
      p2: p2KeyboardOrTouch()       // 双人：P2专用
    };
  }
}
```

关键点：单人那套merged逻辑完全不动，只是在dual模式下不调用它。

## 准备阶段标签

### 显示规则

- 只在3秒倒计时阶段显示P1/P2标签
- 标签位置：靠近各玩家出生点
- 倒计时结束（"Go"出现）后，标签立即隐藏

### 实现方式

利用现有状态机：
- 后端已有countdown / showsCountdown / "Go"等逻辑
- renderer在准备阶段额外画两行字（P1/P2标签）
- 倒计时结束后不再画

---

## 结算与重开

### 结算显示

- 屏幕中间大字："P1 WIN" / "P2 WIN"
- 下方两个按钮：
  - "再来一局"（双方按普攻也可触发）
  - "返回模式选择"

### 手机端适配

- 现有"Press R to reset"只适用于键盘
- 需要DOM按钮支持触控重开

---

## 明确不做的东西

| 类别 | 不做 |
|------|------|
| HUD | 蓄力条、能量条、血条卡片 |
| 提示 | "为什么不能放大"、"怎么死的"解释性UI |
| 命中反馈 | HUD闪红、震动、"HIT"字样 |
| 状态卡片 | 动作状态条、充能百分比显示 |

```
│   ├── ui_p2.ts        # P2输入状态（DOM容器倒置）

```

---

## 验收标准

1. 单人模式完全不受影响（键盘合并、UI布局、游戏逻辑）
2. 双人模式桌面端：左右分坐，键位互不抢
3. 双人模式手机端：上下对坐，P2 UI倒置
4. 准备阶段显示P1/P2标签，开战后隐藏
5. 双方Ready后才开局
6. 结算后可快速重开
