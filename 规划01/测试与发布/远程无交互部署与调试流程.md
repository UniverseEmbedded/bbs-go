# 远程无交互部署与调试流程

本文档用于沉淀一套“无交互、纯命令”的远程推送/部署/验收/排障流程，目标是：可复现、可回滚、失败可定位。所有真实凭据必须由运行环境注入，不进入仓库。

相关：
- 运维 Runbook：[`运维Runbook（故障与操作手册）.md`](运维Runbook（故障与操作手册）.md)
- 代理协议（敏感信息与占位符）：[`AGENTS.md`](../../AGENTS.md)

---

## 1. 基本原则

- 全流程无交互：不手动 SSH 登录、不在远端编辑文件、不依赖交互式提示。
- 最小发布集：只推送“真正影响运行”的文件，减少传输体积与变更面。
- 失败即停止：远端脚本使用 `set -euo pipefail`，探针使用 `curl -fsS`。
- 先构建后推送：尽量避免远端在线构建；构建产物作为部署输入归档，便于回滚。

---

## 2. 流程总览（四段式）

1) 本地构建产物（确定性输入）
2) 打包最小发布集（可归档）
3) 无交互上传 + 解压覆盖（幂等）
4) 远端无交互执行 + 验收探针（可定位）

---

## 3. 输入与最小发布集

建议每次推送只包含：

- `docker-compose.yml`
- `server/go/`（Go 服务端逻辑与二进制构建输入）
- `server/web_dist/`（网站构建产物）

说明：
- `server/web_dist/` 由 `pnpm -C duel-app run build:website` 生成。
- 若目标仅是更新网站，可只推送 `server/web_dist/` 并重启（或不重启，取决于静态文件挂载方式）。

---

## 4. 远端执行脚本模板（失败即停）

远端脚本统一采用：

```bash
set -euo pipefail
```

含义：
- `-e` 任一命令失败立即退出
- `-u` 未定义变量直接失败
- `-o pipefail` 管道任一步失败都算失败

探针统一采用：

```bash
curl -fsS <URL>
```

含义：
- `-f` 非 2xx 直接失败
- `-sS` 静默但保留错误信息

## 5. 无交互远程推送（推荐：脚本化）

推荐做法：本地生成一个 `.tar.gz`，上传到远端固定路径，再在远端固定目录解压覆盖。

优点：
- 可复现：发布包就是“部署输入”
- 可回滚：保留上一份发布包即可回退
- 少依赖：不要求远端有编译环境

可选示例脚本（占位符版）：
- `tools/deploy/remote_bundle_and_apply.py`（配套说明见 `tools/deploy/README.md`）

注意：
- 本仓库不包含任何真实 host/user/password/client id 等信息；请使用环境变量注入。

## 6. 无交互部署与验收（探针清单）

### 6.1 启动/更新服务

```bash
docker compose up -d --build
```

### 6.2 健康检查（建议轮询）

```bash
for i in $(seq 1 80); do
  if curl -fsS http://127.0.0.1/api/v1/health >/dev/null 2>&1; then break; fi
  sleep 1
done
curl -fsS http://127.0.0.1/api/v1/health
```

### 6.3 页面与静态资源探针

```bash
curl -fsSI http://127.0.0.1/privacy | sed -n '1,20p'
curl -fsS  http://127.0.0.1/privacy | head -n 5
```

```bash
curl -fsSI http://127.0.0.1/ephem-cache/manifest.json | sed -n '1,30p'
curl -fsSI http://127.0.0.1/ephem-cache/bodies/planet_earth_399_wrt_sun_seg000.eph.gz | sed -n '1,35p'
```

## 7. 常见排障套路（从外到内）

### 7.1 404 / 空页

检查顺序：
- 构建产物是否存在：`server/web_dist/privacy.html`
- 静态目录是否正确挂载到容器：`WEBDIR` 与 volume 映射
- 路由映射是否存在：例如 `/privacy -> /privacy.html`

### 7.2 更新不生效（缓存相关）

建议原则：
- HTML：`no-cache`
- hash 静态资源：`immutable`
- 固定路径 JSON/manifest：`no-cache`

## 8. 敏感信息与脱敏要求

- 任何真实凭据与环境标识必须通过运行环境注入，不进入仓库。
- 命令与日志输出不得回显口令、密钥、OAuth client id/secret、`.env` 内容。
