# 联机 UI 规格（LAN 开服与房间列表）

本文档定义 LAN 联机（单 Server 多房间，protocol=2）的 UI 信息架构、界面组件、交互与文案规范。

适用范围：

- 桌面/安卓 App（Tauri）完整支持：开服、发现、连接、房间管理（Host-only）。
- 纯 Web：仅支持发现/手动连接与加入，不支持端内开服（若未来接入独立 Server，可具备完整 join 能力）。

---

## 1. 设计目标与原则

### 1.1 目标

- 用户能在不理解 wsUrl/udp/mdns/source 的情况下完成：发现服务器 → 浏览房间 → 输入房间识别码 → 选择角色 → 加入对局。
- “发现列表”对用户呈现为“服务器入口/房间大厅”，而不是抽象的服务条目。
- 房间识别码为“按房间独立”，不在公共房间列表中明文暴露。
- 仅主机可创建/管理房间，权限在 UI 上清晰可见。
- 同机多开（Level 3）在 UI 上自然成立：能区分多个 Server 实例，连接与开服不会产生“假成功/静默失败”。

### 1.2 原则

- 人话优先：面向用户不展示 `udp/mdns/both`、`hostId`、`protocol` 等实现细节（可在“详情”折叠展示）。
- 操作优先：按钮应表达动作（进入/加入/断开/复制邀请），避免“点一下去填输入框”的隐式行为。
- 状态可见：连接中/失败原因/房间满员/识别码错误必须就地可见。

---

## 2. 组件总览

### 2.1 常驻 Net HUD（不可关闭）

展示内容（联机相关最小集）：

- 网络状态：未连接/连接中/已连接/断开原因
- 当前角色：你是 P1 或 P2（加入房间后）
- 房间占槽：P1/P2 是否已连接（加入房间后）
- RTT：平滑 RTT（毫秒）
- 关键动作：断开（永远可达）

说明：Net HUD 细节与指标已在联机方案中确认；本文件只规定它必须在联机模式可见且不可被 LAN 面板关闭。

### 2.2 LAN 面板（可关闭）

LAN 面板负责“配置/操作/详情”，可关闭但必须随时可再次打开（桌面/安卓均不应出现入口消失）。

面板导航采用两页签：

- 加入房间（默认页）
- 开服（仅 Tauri 可见；纯 Web 显示禁用提示）

---

## 3. 加入房间（Join）页

### 3.1 顶部栏

- 标题：局域网联机
- 右侧：关闭（×）

### 3.2 发现区（mDNS 主路径）

标题行：

- 左：服务器（N）
- 右：刷新按钮 + 扫描状态（扫描中…/已更新/扫描失败）

#### 3.2.1 条目形态：Server 卡片

每个条目代表一个“Server 实例入口”（不是房间本身）。

必显字段：

- 展示名：`serverName`（如 Duel.io）
- 区分标识：`#短ID`（例如 hostId 前 4~6 位或端口后缀；用于同名多实例区分）
- 地址摘要：`IP:端口`（从 wsUrl 提取）
- 新鲜度：`X 秒前在线`（由 ageMs 计算）
- 安全徽标：`存在加密房间` 或 `仅公开房间`（基于服务端能力与房间目录统计，详见 4.3）

主要操作：

- 进入：进入该 Server 的“房间列表”页面（Room Browser）
- 复制地址：复制 `wsUrl` 或 `IP:端口`（用于跨设备粘贴）

可选（折叠详情）：

- 发现方式：mDNS（主）/UDP（回退）（仅诊断用）

#### 3.2.2 排序与稳定性

- 默认排序：新鲜度优先（ageMs 升序）。
- 列表刷新时应尽量保持条目位置稳定：
  - 同一 serverId 的条目保持原位置，仅更新“X 秒前在线”与状态标记。
  - 新出现的条目插入顶部或按排序规则插入，但避免每 500ms 全列表重排。

#### 3.2.3 空状态

当列表为空时展示：

- 文案：未发现局域网服务器
- 提示：确认设备在同一 Wi‑Fi；或使用下方“手动连接”
- 按钮：手动连接（滚动并聚焦到地址输入框）

### 3.3 手动连接区（兜底路径）

输入：

- 地址：支持 `ws://ip:port`；也支持 `ip:port`（自动补 `ws://`）

按钮：

- 连接

错误提示（就地显示）：

- 地址格式不正确
- 连接超时
- 连接被拒绝

成功后进入“房间列表”页面。

---

## 4. 房间列表（Room Browser）

该页面在“用户已选定某个 Server 实例”后出现（通过发现卡片进入或手动连接成功）。

### 4.1 顶部栏

- 左：返回（回到 Join 页的发现列表）
- 中：服务器：{serverName} {#短ID}
- 右：断开

### 4.2 房间列表（Rooms）

标题行：

- 左：房间（M）
- 右：刷新（重新拉取 rooms；可选自动轮询）

条目字段：

- 房间名：`name`
- 状态：空闲/进行中/结算中（映射自 `RoomSummary.state`）
- 人数：`P1 空/已连接`、`P2 空/已连接`
- 识别码徽标：
  - `需识别码`（codeRequired=true）
  - `无需识别码`（codeRequired=false）

条目操作：

- 加入为 P1
- 加入为 P2
-（可选）快速加入：自动选择空位（在列表顶部提供一个全局按钮，不在每条里重复）

禁用规则：

- 对应槽位已占用：该槽位加入按钮禁用并显示原因（该位置已被占用）。
- 房间满员：两按钮均禁用并显示（房间已满）。
- 房间进行中且不支持中途加入：两按钮均禁用并显示（对局进行中，暂不支持加入）。

### 4.3 房间识别码输入（按房间独立）

触发条件：

- 用户点击加入某个 `codeRequired=true` 的房间时。

交互：

- 弹出输入对话框（或页面内滑出层）：
  - 标题：加入房间：{房间名}
  - 输入：3 位识别码（数字键盘/number input）
  - 按钮：确认加入 / 取消
  - 辅助：识别码由房主提供

错误提示映射：

- `bad_room_code`：识别码错误，请重试
- `rate_limited`：请稍候再试

说明：

- 房间列表中不显示识别码明文。
- Host 在创建房间成功后会得到 roomCode，用于在“开服页/房间管理”中展示与复制邀请。

## 5. 开服（Host）页（仅 Tauri）

纯 Web 展示：

- 端内开服仅在桌面/安卓 App 可用

### 5.1 服务器状态卡

显示字段：

- 状态：未开服 / 启动中 / 运行中 / 启动失败（含原因）
- 地址：本机可连接地址（IP:端口）与可复制 wsUrl
- 运行指标（可选）：已创建房间数、在线玩家数

操作：

- 启动服务器
- 停止服务器

要求：

- 启动失败（端口占用/权限等）必须在此处明确展示，禁止“看似运行中但实际不可连接”。

### 5.2 房间管理（仅主机可建房）

#### 5.2.1 创建房间

按钮：创建房间

创建弹窗字段：

- 房间名（可选）
- 是否启用识别码（开关）
- 识别码（3 位，开关打开时必填；支持自动生成）

创建成功反馈：

- 弹出提示：已创建房间：{房间名}，识别码：{roomCode}
- 提供按钮：复制邀请（见 5.3）

#### 5.2.2 房间列表（主机视角）

条目显示与 Join 页一致，额外提供 Host-only 操作：

- 重命名
- 关闭房间
- 复制邀请

关闭房间确认：

- 二次确认（房间内有人时需强调会断开房间会话）。

### 5.3 邀请分享

“复制邀请”生成的人话文本建议格式：

- 局域网联机：服务器 {serverName} {#短ID}
- 地址：{IP:端口}
- 房间：{房间名}
- 识别码：{roomCode}

二维码（可选）：

- 仅作为增强，不作为基本功能依赖。

## 7. 远程联机（EasyTier / 远程当 LAN）

本节定义“远程当 LAN”的 UI 呈现与文案口径。该模式不改变联机协议与房间逻辑，只改变“网络可达性”。

### 7.1 信息架构

在 LAN 面板中新增页签：

- 远程联机（EasyTier）（Tauri 桌面/安卓可用；纯 Web 显示说明与手动连接兜底）

### 7.2 透明告知（开源态度）

透明告知与第三方入口节点的口径以 [EasyTier 远程当 LAN 方案.md](./EasyTier%20%E8%BF%9C%E7%A8%8B%E5%BD%93%20LAN%20%E6%96%B9%E6%A1%88.md) 的“入口节点（Public Servers）与开源态度声明”为准。

### 7.3 入口节点选择（Public Servers）

界面提供：

- 默认入口列表（可一键恢复）
- 自定义增删（支持 `tcp://...` 与 `https://...`）
- 开关：停止使用第三方节点（开启后默认入口列表为空，仅允许自建/自填）

### 7.4 操作流程（最小可用）

房主侧：

- 启动 EasyTier
- 一键开服
- 复制“可分享连接地址”（必须包含可达地址，不能是 127.0.0.1）

加入侧：

- 启动 EasyTier
- 粘贴房主的 `wsUrl` 并连接

### 7.5 错误提示与降级

必须覆盖：

- EasyTier 启动失败（权限/缺少组件/端口冲突）
- 入口节点不可用（超时/拒绝/解析失败）
- 网络已加入但对方 `wsUrl` 不可达（给出“检查地址/切换入口/改用手动连接”的提示）
- 超时：连接超时：确认双方在同一 Wi‑Fi，或检查地址与端口
- 断开：已断开：{原因}

房间相关：

- 房间不存在：房间不存在或已关闭
- 房间已满：房间已满，请选择其它房间
- 位置占用：该位置已被占用，请选择另一位置
- 对局进行中：对局进行中，暂不支持加入

权限相关：

- 非房主建房：只有房主可以创建房间

## 7. 与协议/状态机的对应关系

关键数据来源：

- 发现列表：mDNS 得到 Server 入口（不含房间列表）。
- 房间列表：`list_rooms → rooms/rooms_update`（protocol=2）。
- 加入房间：`join_room → join_room_ack/join_room_reject`（含 roomCode 校验）。
- 房间内占槽/对手状态：`room_state` 为权威来源。
- RTT：`ping/pong` 计算（EMA 平滑）。
