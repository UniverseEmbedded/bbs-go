# 仓库结构优化

本文档记录仓库目录结构的优化建议，待现有主线功能（账号系统、公网联机、社区论坛）完成后执行。

---

## 当前结构

```
duel/
├── .github/workflows/
├── duel-app/
│   ├── src/                    # TS 前端
│   └── src-tauri/
│       ├── src/                # Tauri 壳
│       └── crates/             # Rust 服务端组件（位置不合理）
│           ├── duel-core/
│           └── duel-server/
├── koishi/                     # QQ 机器人
├── server/
│   ├── go/                     # Go Web 服务端
│   └── web_page/               # 官网星图（位置不合理）
├── sketch/                     # 原始草图
├── tools/                      # 工具脚本（定位模糊）
└── 规划01/                     # 文档
```

---

## 问题分析

### 1. `server/web_page/` 语义错误

- **问题**：这是官网星图的前端代码，放在 `server/` 下语义不对
- **影响**：server 应该只包含服务端代码，前端代码混入造成混淆

### 2. Rust crates 嵌套过深

- **问题**：`duel-core` 和 `duel-server` 放在 `duel-app/src-tauri/crates/` 下，但它们是独立的服务端组件，不是 Tauri 客户端的一部分
- **影响**：
  - 语义混淆：服务端代码放在客户端目录下
  - 构建耦合：服务端构建依赖 Tauri workspace 配置

### 3. `tools/` 目录定位模糊

- **问题**：目前只有 `ephem/` 星历相关工具，与其他组件关系不明确
- **影响**：难以判断这些工具属于哪个子系统

---

## 建议结构

```
duel/
├── .github/workflows/
├── duel-app/                   # Tauri 客户端
│   ├── src/                    # TS 前端
│   └── src-tauri/              # Tauri 壳
├── crates/                     # Rust 服务端组件（从 duel-app 移出）
│   ├── duel-core/              # 核心逻辑库
│   └── duel-server/            # 联机服务端
├── server/                     # 服务端
│   ├── go/                     # Go Web 服务端
│   └── bbs-go/                 # 社区论坛（git submodule）
├── koishi/                     # QQ 机器人
├── website/                    # 官网星图（从 server/web_page 移出）
│   ├── index.html
│   ├── about.html
│   ├── css/
│   ├── js/
│   └── public/
├── scripts/                    # 工具脚本（原 tools/）
├── sketch/                     # 原始草图（参考用）
└── 规划01/                     # 文档
```

---

## 执行步骤

### 阶段 1：低风险调整

| 步骤 | 操作 | 影响 |
|------|------|------|
| 1.1 | `server/web_page/` → `website/` | 需更新 Go 服务端 WebDir 配置 |
| 1.2 | `tools/` → `scripts/` | 仅影响脚本调用路径 |

### 阶段 2：高风险调整

| 步骤 | 操作 | 影响 |
|------|------|------|
| 2.1 | 创建根目录 `crates/` | 新建 Cargo workspace |
| 2.2 | 移动 `duel-core` 和 `duel-server` | 需更新 Cargo.toml 路径、CI 配置、AGENTS.md 验证命令 |
| 2.3 | 更新所有文档引用 | AGENTS.md、规划文档中的路径 |

---

## 风险评估

| 调整 | 风险等级 | 说明 |
|------|----------|------|
| web_page → website | 低 | 仅配置变更 |
| tools → scripts | 低 | 仅路径变更 |
| Rust crates 移出 | 高 | 涉及 Cargo workspace 重构、CI 配置、文档更新 |

---

## 执行时机

**在以下事项完成后执行：**

- 里程碑 E：账号系统
- 公网联机
- 社区论坛集成

**原因：**

1. 避免在主线开发期间引入额外的路径变更
2. Rust crates 移出会影响构建流程，需要集中精力处理
3. 确保所有功能正常运行后再做结构性调整
