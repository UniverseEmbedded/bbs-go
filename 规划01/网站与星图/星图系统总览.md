# 星图系统总览

本文档定义官网星图系统的整体架构、技术栈与模块关系。

---

## 项目定位

星图系统是天文层的实现基底与独立测试入口，同时也承担官网门面的展示功能。用户可以：

- 查看太阳系八大行星、卫星、矮行星的实时位置
- 聚焦任意天体，观察其轨道与卫星
- 切换明/暗主题，适配不同浏览环境

**与游戏项目的关系**：星图系统将被改造为“天文层（可独立测试的完成品）”的主实现载体与原型环境，具体验收与范围见 [开发流程里程碑.md](../总览与路线/开发流程里程碑.md) 的“里程碑I：天文层（可独立测试的完成品）”。

## 技术栈

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 3D 渲染 | three.js | 场景图、相机、几何体 |
| 相机控制 | OrbitControls | 鼠标/触屏旋转缩放 |
| 星历缓存 | 自研 EphemCache | 按需加载、线性插值 |
| UI 控制 | 原生 TypeScript | 无框架依赖 |
| 构建工具 | Vite | 开发服务器、打包 |
| 数据源 | JPL Horizons API | 高精度星历数据 |

## 核心模块

```
server/web_page/js/
├── solar-system.ts    # SolarSystemApp 类 - three.js 渲染
├── ephem.ts           # EphemCache 类 - 星历数据缓存
├── main.ts            # AppController 类 - UI 控制
└── translations.ts    # 多语言文本
```

### 模块职责

| 模块 | 职责 | 依赖 |
|------|------|------|
| SolarSystemApp | 创建场景、天体、轨道线；动画循环；相机过渡 | three.js, EphemCache |
| EphemCache | 加载 manifest；按需请求段文件；位置插值 | fetch API, DecompressionStream |
| AppController | DOM 事件绑定；主题切换；语言切换；聚焦控制 | SolarSystemApp, i18next |

### 数据流

```
JPL Horizons API
       │
       ▼ (离线生成)
tools/ephem/horizons_cache.py
       │
       ▼ (输出)
server/web_page/public/ephem-cache/
       │
       ▼ (运行时加载)
EphemCache.getPositionKm(key, jd)
       │
       ▼ (传入)
SolarSystemApp._animate()
       │
       ▼ (渲染)
three.js Scene
```

## 天体数据

### 内置天体

| 类型 | 天体 |
|------|------|
| 恒星 | 太阳 |
| 行星 | 水星、金星、地球、火星、木星、土星、天王星、海王星 |
| 卫星 | 月球、火卫一/二、木卫一~四、土卫一~八、天卫一~五、海卫一 |

### 动态加载

矮行星（冥王星、谷神星等）及其卫星从星历缓存动态发现并加载。

---

## 渲染特性

### 天体表示

- **主体球体**：MeshStandardMaterial，带轴向倾斜
- **强调球体**：BackSide 渲染的稍大球体，用于视觉突出
- **指示环**：始终面向相机的 RingGeometry，显示天体位置
- **指示线**：沿轴向的垂直线（仅有限倾角天体）

### 轨道线

- 从星历数据动态生成
- 优先绘制一个完整周期
- 支持卫星轨道（相对于宿主行星）

### 动画

- **自转**：基于 rotationPeriodHours 计算
- **公转**：从星历数据实时查询位置
- **相机过渡**：聚焦天体时的平滑移动

## 主题系统

| 模式 | 背景 | 轨道线 | 强调色 |
|------|------|--------|--------|
| 浅色 | 透明/浅色 | 黑色 | 黑色 |
| 深色 | 透明/深色 | 白色 | 浅绿 |

## 多语言支持

使用 i18next 实现，支持：

- 中文（zh）
- 英文（en）

语言偏好存储在 localStorage，浏览器语言作为默认值。

## 作为天文层完成品的扩展范围

在保持“可网页独立运行/可独立测试”的前提下，天文层完成品需要在星图系统之上补齐以下能力（范围以里程碑I为准）：

- 荷载轨道物理模拟与事件系统（到达/遭遇/LocalSystem等）
- 空间站（挂靠/补给/分段航行）
- 质量驱动器外观与交互（天文层表现与操作反馈）
- UI/UX：时间控制、操作确认与失败提示、日志与复盘入口、性能与实体上限护栏

天文层规则与设定参考：规划13 [天文移动与速度体系.md](../../规划13/航行与移动/天文移动与速度体系.md)、[空间站与分段航行.md](../../规划13/航行与移动/空间站与分段航行.md)、[荷载规模、LOD聚合与防炸服上限.md](../../规划13/荷载规模、LOD聚合与防炸服上限.md)。
