# 星历数据规格

本文档定义星历数据的来源、格式、生成工具与前端加载流程。

---

## 数据源

### JPL Horizons API

星历数据来自 NASA JPL Horizons 系统，提供太阳系天体的高精度状态向量。

| 属性 | 值 |
|------|-----|
| API 端点 | `https://ssd.jpl.nasa.gov/api/horizons.api` |
| 数据类型 | VECTORS（状态向量） |
| 坐标系 | ECLIPJ2000（黄道坐标系 J2000） |
| 单位 | 位置 km，速度 km/s |

### API 限制

- 单次响应体积上限：100MB（可配置）
- 请求频率：建议间隔 > 0.4 秒
- 重试策略：6 次，指数退避

## 生成工具

### 目录结构

```
tools/ephem/
├── horizons_cache.py     # 主生成脚本
├── satellite_ids.py      # 卫星 ID 清单生成
├── dwarfs.json           # 矮行星定义
└── README.md             # 使用说明
```

### 生成卫星清单

```bash
cd tools/ephem
python satellite_ids.py
```

输出 `satellite_ids.json`，包含各行星系统的卫星 NAIF ID。

### 生成星历缓存

```bash
python horizons_cache.py \
  --satellite-ids satellite_ids.json \
  --out-dir ../../server/web_page/public/ephem-cache \
  --start 2026-01-01 \
  --stop 2037-01-01
```

### 输出文件

```
server/web_page/public/ephem-cache/
├── manifest.json                    # 元数据清单
└── bodies/
    ├── planet_earth_399_wrt_sun_seg000.eph.gz
    ├── planet_earth_399_wrt_sun_seg001.eph.gz
    ├── moon_301_wrt_earth_399_seg000.eph.gz
    └── ...
```

## 二进制格式（EPH1）

段文件（`.eph.gz`）解压后为 EPH1 格式，按小端序存储：

### 头部（24 字节）

| 偏移 | 类型 | 字段 | 说明 |
|------|------|------|------|
| 0 | 4 bytes | magic | 固定为 `EPH1`（0x45 0x50 0x48 0x31） |
| 4 | uint32 | version | 版本号，当前为 1 |
| 8 | float64 | jd0 | 起始儒略日（JDTDB） |
| 16 | uint32 | step_seconds | 采样步长（秒） |
| 20 | uint32 | count | 样本数量 |

### 样本数据

紧接头部，`count × 6 × float32` 字节：

| 字段 | 类型 | 说明 |
|------|------|------|
| x | float32 | X 坐标（km） |
| y | float32 | Y 坐标（km） |
| z | float32 | Z 坐标（km） |
| vx | float32 | X 速度（km/s） |
| vy | float32 | Y 速度（km/s） |
| vz | float32 | Z 速度（km/s） |

### 坐标系

所有位置和速度均在 **ECLIPJ2000** 坐标系下：

- 原点：太阳系质心或指定中心天体
- X 轴：指向春分点（J2000）
- Z 轴：垂直于黄道面，指向北
- Y 轴：右手系

## manifest.json 结构

```json
{
  "start": "2026-01-01",
  "stop": "2037-01-01",
  "frame": "ECLIPJ2000",
  "units": {
    "position": "km",
    "velocity": "km/s"
  },
  "format": {
    "segment_magic": "EPH1",
    "version": 1,
    "encoding": "gzip",
    "record_layout": "jd0(float64), step(uint32), count(uint32), samples(count * 6*float32)"
  },
  "bodies": [
    {
      "key": "planet_earth_399_wrt_sun",
      "kind": "planet",
      "command": "399",
      "center": "500@10",
      "period_seconds": 31557600.0,
      "step_seconds": 43200,
      "segments": [
        {
          "file": "planet_earth_399_wrt_sun_seg000.eph.gz",
          "count": 1000,
          "jd0": 2460676.5,
          "step_seconds": 43200
        }
      ]
    }
  ]
}
```

### 字段说明

| 字段 | 说明 |
|------|------|
| key | 天体唯一标识 |
| kind | 类型：planet / moon / satellite / dwarf / dwarf_moon |
| command | Horizons COMMAND 参数（NAIF ID） |
| center | Horizons CENTER 参数 |
| period_seconds | 轨道周期（秒），可为 null |
| step_seconds | 采样步长（秒） |
| segments | 段文件列表，按 jd0 排序 |

## 天体键命名规范

| 类型 | 格式 | 示例 |
|------|------|------|
| 行星 | `planet_{name}_{id}_wrt_sun` | `planet_earth_399_wrt_sun` |
| 月球 | `moon_{id}_wrt_earth_{earth_id}` | `moon_301_wrt_earth_399` |
| 卫星 | `sat_{host}_{id}_wrt_{host_id}` | `sat_jupiter_501_wrt_599` |
| 矮行星 | `dwarf_{name}_primary_wrt_sun` | `dwarf_pluto_primary_wrt_sun` |
| 矮行星卫星 | `dwarf_{name}_moon_{id}_wrt_primary` | `dwarf_pluto_moon_901_wrt_primary` |

## 时间范围与更新策略

### 默认范围

- 起始：2026-01-01
- 结束：2037-01-01
- 覆盖：约 11 年，包含 2036 全年

### 更新策略

1. **按需扩展**：当接近结束时间时，重新运行生成脚本扩展范围
2. **增量更新**：使用 `--resume` 参数跳过已下载的段
3. **版本管理**：manifest.json 包含时间范围，前端可检测是否需要更新

## 前端加载流程

### EphemCache 类

```typescript
const ephem = new EphemCache('/ephem-cache');

// 初始化：加载 manifest
const ok = await ephem.init();
if (!ok) {
  console.error(ephem.lastError);
}

// 获取当前儒略日
const jd = ephem.nowJd();

// 获取位置（km）
const pos = ephem.getPositionKm('planet_earth_399_wrt_sun', jd);
// => { x: number, y: number, z: number }

// 强制加载（用于预加载）
await ephem.requirePositionKm('planet_mars_499_wrt_sun', jd);
```

### 加载策略

1. **延迟加载**：段文件在首次查询时按需请求
2. **缓存**：已加载的段保存在内存中
3. **插值**：对任意儒略日进行线性插值

### 坐标转换

前端渲染使用 three.js 右手坐标系，需要将 ECLIPJ2000 坐标转换：

```typescript
// ECLIPJ2000: x, y, z
// three.js:   x, z, y（Y/Z 交换）
function mapEclipticToThree(x, y, z) {
  return new THREE.Vector3(x, z, y);
}
```

## 错误处理

### 常见错误

| 错误 | 原因 | 处理 |
|------|------|------|
| `manifest fetch failed` | 网络问题或路径错误 | 显示错误提示 |
| `no segment for {key}` | 时间超出范围 | 隐藏该天体 |
| `gzip not supported` | 浏览器不支持 DecompressionStream | 降级提示 |

### 降级策略

- 星历不可用时：天体位置不更新，显示警告
- 部分天体缺失：仅隐藏缺失天体，其他正常显示
