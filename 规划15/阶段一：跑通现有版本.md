# 阶段一：跑通现有版本（禁用 Docker）

验收目标：Go 服务端能被打包出来并且启动；前端无需考虑报错。

## 环境

- Windows（PowerShell）
- Go：已安装并可用（`go version` 可输出）
- Docker：不使用

## 构建（打包）

在仓库根目录执行：

```powershell
if (!(Test-Path .\logs)) { New-Item -ItemType Directory -Path .\logs | Out-Null }
go build -o .\bbs-go.exe .
```

产物：`.\bbs-go.exe`

## 启动（不依赖 MySQL/SQLite）

说明：默认没有 `bbs-go.yaml` 时，程序会使用默认配置启动，且 `Installed=false` 不会初始化数据库连接与迁移；因此可直接跑起来用于验证“能启动”。

```powershell
.\bbs-go.exe
```

预期现象（示例）：

- 控制台出现 Iris 启动信息
- 监听 `http://localhost:8082`

可用性检查（返回 200 即可）：

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8082/api/config/configs
```

## 可选：初始化为 SQLite（仍然不需要 Docker）

如果希望后续能完成安装并写入配置/数据库，可走安装接口选择 SQLite：

```powershell
$body = @{
  siteTitle = "bbs-go"
  siteDescription = "local"
  baseURL = "/"
  dbConfig = @{ type = "sqlite" }
  username = "admin"
  password = "admin123456"
  avatar = ""
  language = "zh-CN"
} | ConvertTo-Json

Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8082/api/install/install -ContentType "application/json" -Body $body
```

安装完成后会在配置文件同目录生成/使用 `bbs-go.db`，并写入 `bbs-go.yaml`。
