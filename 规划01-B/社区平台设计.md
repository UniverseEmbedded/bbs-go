# 社区平台设计

> 【需要详细讨论】

本文档定义社区平台的整体设计，包括功能定位、技术选型和实施路径。

---

## 平台定位

**论坛 + 投票 + 捐赠 三合一社区平台**

| 功能模块 | 说明 |
|----------|------|
| 论坛 | 帖子、评论、点赞、用户互动 |
| 投票 | 决策投票（参考 Loomio 四象限投票逻辑） |
| 捐赠 | 支持国际支付（面向国际用户） |

### 目标用户

- 面向国际用户
- 支持多语言

---

## 技术选型

### 后端：bbs-go

| 项目 | 说明 |
|------|------|
| 技术栈 | Go（与现有 Go 服务端统一） |
| 功能覆盖 | 论坛 ✅、投票 ✅、捐赠 ❌ |
| 开源状态 | 后端开源，前端闭源 |

### 前端：自开发

**原因：** bbs-go 最新版前端源码未公开

**策略：**
- 基于 fe26ad02 提交的前端源码（最后一个开源版本）
- 自行对接新版后端 API
- 按需开发捐赠功能
- 工程约束见 [bbs-go工程集成约束.md](./bbs-go工程集成约束.md)

---

## 功能模块

### 1. 论坛（bbs-go 已有）

- 帖子发布、编辑、删除
- 评论、回复
- 点赞、收藏
- 用户主页
- 标签/分类

### 2. 投票（bbs-go 已有，需增强）

**现有功能：**
- 基础投票 API

**待研究：**
- Loomio 四象限投票逻辑（同意/需要修改/阻止/弃权）
- 投票模板
- 投票结果可视化

### 3. 捐赠（需自开发）

**bbs-go 无此功能，需自行开发：**

| 方案 | 说明 |
|------|------|
| 简单版 | 外链到 Patreon/Ko-fi/GitHub Sponsors |
| 集成版 | 后端新增捐赠记录表 + 前端展示捐赠者 |
| 完整版 | 接入 Stripe/PayPal + 会员权益 |

## 实施路径

### 阶段 1：bbs-go 集成

| 步骤 | 任务 |
|------|------|
| 1.1 | 以 git submodule 引入 bbs-go 到 `server/bbs-go/` |
| 1.2 | 后端升级到最新提交（01cb26a7） |
| 1.3 | 以 fe26ad02 为前端源码基线，自维护 site/admin 前端 |
| 1.4 | 不接入 bbs-go 登录体系，统一走 Go 服务端 JWT |
| 1.5 | 采用新版 `/res` 静态资源挂载 |

### 阶段 2：前端对接

| 步骤 | 任务 |
|------|------|
| 2.1 | 跑通基础论坛功能 |
| 2.2 | 对接投票 API |
| 2.3 | 与 Go 服务端 JWT 认证集成 |
| 2.4 | 适配 `baseURL` 与 `scriptInjections` 配置下发 |
| 2.5 | 任务中心（仅积分）按需接入 |

### 阶段 3：捐赠功能

| 步骤 | 任务 |
|------|------|
| 3.1 | 确定捐赠方案（外链/集成/完整） |
| 3.2 | 开发后端 API |
| 3.3 | 开发前端页面 |
